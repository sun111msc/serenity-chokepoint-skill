## 核心理念

> "在这个系统里，谁是那个沉默的、不可替代的物理开关？"

从顶层需求逐层逆向拆解产业链，寻找第 3-7 层被市场忽视的关键物理瓶颈——只有 1-2 家供应商、不可替代、市值严重低估的公司。

## 方法论核心武器

1. **七层供应链逆向拆解** — 从终端需求逐层往上挖到最底层原料
2. **对抗性 AI 验证（Devil's Advocate）** — 发布结论前用 AI 攻击自己的逻辑
3. **三阶段资金轮动择时** — HBM → 光模块 → CPO/硅光子
4. **物理-地缘坐标地图** — 四维整合：地理 + 技术 + 地缘 + 财务
5. **三种认知套利模型** — 相对价值博弈 / 代码碰撞信息差 / 机械恐慌抄底
6. **另类数据挖掘矩阵** — 专利、海关、GitHub、论文、行业 PPT
